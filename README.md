# SuiteCRM PhoneNumbers Module

## Функционал
Модуль представляет из себя список номеров телефонов. \
Максимальная длина номера 25 символов. \
Разрешенные символы: цифры 0-9, "+", "*". \
При сохранении записи из номера удаляются все символы, кроме разрешенных. \
При просмотре записи номер окрашивается в зеленый, если содержит 10 символов, иначе - в красный.

## Инструкция
1. Убедиться, что установлены docker и docker compose (либо docker desktop)
2. Клонировать репозиторий
```shell
git clone https://github.com/bruher24/irbis_task.git <ваш_путь>
```
```shell
cd <ваш_путь>
```
3. Собрать и развернуть проект
```shell
docker compose up --build -d
```
4. Перейти на localhost \
Логин: admin \
Пароль: root
